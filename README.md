## 00 / The work

I’m Abdul Sameer, an AI/ML and full-stack developer in Bengaluru. I build practical systems that connect models to usable products: computer-vision pipelines, multilingual health tools, agricultural diagnostics, and operational dashboards.

I’m pursuing a B.E. in Information Science Engineering at HKBK College of Engineering (2024–2028). My focus is end-to-end product work across model integration, APIs, interfaces, and deployment.

## 01 / Selected systems

**01 — [QueueIQ](https://github.com/Sameer8549/QueueIQ)** · [Live demo](https://queueiq.vercel.app/)
Hospital queue intelligence for multilingual patient workflows. Voice intake, BioBERT symptom understanding, Gemini + ChromaDB health education, and a FastAPI backend. Reached the Matrix Fusion 4.0 finale with Team Cipher.

**02 — [AgriVision](https://github.com/Sameer8549/Agrivision-ai-yit)**
Crop-disease diagnostics combining a React interface, FastAPI service, YOLOv8, and localized AI treatment guidance. Built for the Matrix Fusion 4.0 finale.

**03 — [CipherRanker](https://github.com/Sameer8549/CipherRanker)** · [Live demo](https://rankker.netlify.app/)
Local-first recruitment analysis with parallel scoring, independent Groq and Mistral rubrics, evidence audits, and ranked CSV exports.

**04 — [NAMMA KSP](https://github.com/Sameer8549/NAMMAKSP)** · [Prototype](https://namma-ksp-50043229029.development.catalystappsail.in/)
Crime-intelligence workflows for FIR analysis, offender history, heatmaps, and investigation support. The public demo uses synthetic data.

**05 — [TARANG](https://github.com/Sameer8549/TARANG)** · [Live demo](https://tarang-50043555806.development.catalystappsail.in/)
Coastal emergency-response console for distress cases, vessel tracking, multilingual alerts, and rescue dispatch.

**06 — [OPTIFRESH](https://github.com/Sameer8549/OPTIFRESH)**
Computer-vision food freshness and safety analysis, combining visual classification with food-condition assessment.

**07 — [HealthLens / HealthCheck AI](https://github.com/Sameer8549/HeathCheckAI)** · [Techsium demo post](https://www.linkedin.com/posts/abdulsameer9_healthlens-demovideo-healthtech-activity-7329375998334885888-BKZS)
Symptom-based health-risk assessment with a web interface. Placed 3rd at the Techsium Hackathon.

**08 — ArogyaLens**
A webcam health-analysis concept linking OpenCV, YOLOv8, NVIDIA Nemotron, Gemini, and FastAPI. Presented at HKBK Technovate 2026. The resume’s linked HealthCheckAI repository currently contains a symptom-analysis app, so I have not linked it here as ArogyaLens source code.

**Also building:** IoT device-monitoring dashboard for telemetry, state tracking, and operational analytics.
